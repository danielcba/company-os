# Cognitive Concept Template

Version: 1.0
Status: Official
Owner: Company OS

---

## Purpose

The Cognitive Concept Template is the standard intellectual structure that every concept of Company OS must follow.

Consistency is part of the architecture.

A concept is not merely a definition.
It is a cognitive capability with a Cognitive Contract: Input → Transformation → Output.

---

## Concept Name

### Definition

Provide a concise and unambiguous definition of the concept.

The definition must answer:

> What is this concept?

State the fundamental nature of the concept in one or two sentences.

### Cognitive Family

Identify the family the concept belongs to.

Perception, Reasoning, Action, or Learning.

### Capability

State the single cognitive capability the concept performs, as a verb.

Capture, Organize, Explain, Generalize, Detect Deviation, Predict, Restructure, Calibrate, Propose, Commit.

## Cognitive Contract

Every concept performs a precise transformation.

### Input

What the concept receives.

### Transformation

What the concept does.

### Output

What the concept produces.

---

## Relationships

Describe how this concept connects with other concepts.

Use the formal relationship types:

- Produces
- Requires
- Supports
- Leads To
- Contradicts
- Refines
- Enables
- Applies To
- Affects
- Improved By

The type set is closed: every relationship in a concept file must be one of these ten types.
