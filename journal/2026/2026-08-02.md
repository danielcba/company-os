## Discoveries

### A closed relationship algebra is possible.

Ten relationship types now cover every interaction between concepts:

`→` `⇠` `⇒` `⟹` `⊣` `▸` `⇢` `↦` `⇝` `←`

Each type has a single meaning and a single notation. Passive inverse forms are documented as equivalents, not new types.

### A closed system can still be complete.

The complete relationship table covers all pairs of the ten Core Concepts.

The ontology, the relationships document, and the concept template were aligned so that no notation collision remains.

### The structure is a single standard.

The repository follows one rule: only the root has README files.

- The lexicon README was removed; the ontology is the only map.
- The `assets/` directory was removed; planned visual assets live in the brand document.

Journaling was redefined: written at the moment the canonical state changes, not by calendar.

---

## Decisions

- Close the relationship type set at ten formal types with unique notation.
- Resolve direction conflicts (Anomaly, Hypothesis, Insight).
- Remove the lexicon README and the `assets/` directory.
- Standardize: README files exist only at the repository root.
- Amend E6: the journal is written at points of canonical change, not daily.
- Repair the journal gap by recording this session.
